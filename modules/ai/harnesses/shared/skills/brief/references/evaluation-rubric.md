# Evaluation rubric

How to turn the claim ledger into honest judgments. Evaluate just-in-time, per card — never evaluate everything up front.

## Confidence is derived, not vibed

Confidence on a key judgment is a function of the SUPPORT marks on its load-bearing claims. Use exactly three words; do not invent "moderately high":

| Word | Means | Ledger state |
|---|---|---|
| **Likely** | I would act on it | Load-bearing rows corroborated |
| **Provisional** | Act with caution; flagged | Rests on single-sourced or unverified rows |
| **Contested** | Credible sources disagree | Conflicting evidence; show the disagreement |

**Split the confidence** when mechanism and state diverge — high on *how it works*, lower on *what is true right now*. Internal state changes daily; the technique is durable. Say both.

## Load-bearing test

A claim is load-bearing if **flipping it changes the user's action**. Only load-bearing-and-weak rows justify more digging. If flipping a claim does not change the decision, do not spend an exhaustive pass on it, however interesting.

## What would change my mind

Every key judgment ends with the disconfirming observation that would flip it — ideally one the user can check themselves ("I'd change this if the Bloc channel isn't live in MX — verify that first"). This proves the conclusion is falsifiable, not motivated, and hands the user a cheap verification path.

## Bias checks (run before briefing)

- **Framing autopsy:** if the user's own materials all lean one way, say so out loud and report that you went looking for the failure case on purpose.
- **Confirmation:** did you seek disconfirming evidence, or only accumulate support?
- **False corroboration:** are the agreeing sources independent in origin, or restatements of one?
- **Motivated reasoning:** if the user clearly wants conclusion X, did you steelman not-X?
- **Calibration:** are the confidence words honest, or inflated to sound useful?

## When to demote a claim

Demote to `unverified` / Provisional, and hedge in speech, when: the citation will not verify against a primary source; the only source has an interest in the conclusion; the claim is a sub-agent paraphrase you could not ground; or it is an internal "current state" claim not confirmed against the system of record.

## The brief is a render of the ledger

Do not build toward a polished document on top of unexamined claims. The verdict, the confidence, and the "what would change my mind" all fall out of the ledger when it is honest. Structure the output as: BLUF → key judgments (each with confidence + load-bearing rows) → disagreements → assumptions/risks → gaps. Disclose the weakest link in the BLUF.
