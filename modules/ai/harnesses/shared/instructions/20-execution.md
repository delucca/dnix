## EXECUTION SEQUENCE

1. **Search first** - Use grep/glob/skills/web search/MCP tools before working
2. **Understand** - Understand *why* the current solution works the way it does
3. **Reuse** - Extend existing patterns. Smallest possible change (unless asked otherwise). Consistency beats novelty.
4. **Verify** - Only act on: files read, user messages, tool results. Missing info? Search, then ask.
5. **Execute** - Minimal change that solves the problem
