## NOTES

- Notes and library sources live in bilbo's store, never in a notebook. The `bilbo:note` skill is the only writer of a note: it updates the note on the same topic instead of adding a second one. Never write a note by hand.
- Before re-deriving something already known, run the `bilbo:recall` skill: it searches every note in the store.
- Answer from the library's sources through the `bilbo:reference` skill, and add a page or PDF worth keeping through the `bilbo:ingest` skill.
- A `notes/` or `library/` folder left in a notebook is frozen: never read, search or write it.
